## 📌 Project Overview
An interactive Car Sales Analysis Dashboard developed using Microsoft Power BI to analyze sales performance, revenue trends, and vehicle sales metrics.

This project uses sample data for learning and portfolio demonstration purposes.

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

## 📊 Key Performance Indicators (KPIs)

### 1. Total YTD Sales ($)
Measures cumulative car sales revenue from the beginning of the year up to the selected date.

### 2. YTD Cars Sold
Tracks the total number of cars sold during the year-to-date period.

### 3. YTD Average Price ($)
Calculates the average selling price of cars during the year-to-date period.

## 📈 Key Business Objectives
- Monitor overall car sales performance.
- Analyze revenue generated from vehicle sales.
- Track the number of cars sold.
- Understand average vehicle selling prices.
- Support data-driven business decisions.

## ⚙️ Technical Implementation
- Data cleaning and transformation using Power Query.
- DAX measures for calculating YTD KPIs.
- Date-based analysis using a Calendar Table.
- Interactive dashboard visualizations.
