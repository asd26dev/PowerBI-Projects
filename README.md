# 🚗 Car Sales Analysis Dashboard | Power BI

## Project Overview
This project presents an interactive Car Sales Analysis Dashboard developed using Microsoft Power BI.

The dashboard helps analyze car sales performance, revenue trends, customer preferences, and vehicle sales using interactive visualizations.

**Note:** This project uses dummy/sample data for portfolio and learning purposes.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Modeling

## Key Analysis
- Total Cars Sold
- Total Sales Revenue
- Average Selling Price
- Sales Trends
- Vehicle Performance Analysis
- Sales Distribution

## Key Features
- Interactive dashboard
- KPI cards
- Dynamic filtering
- Sales performance visualization
- Business insights

## Project Files
- Power BI Dashboard (.pbix)
- Dashboard Screenshots

## Objective
To demonstrate practical skills in data cleaning, data modeling, DAX calculations, and interactive dashboard development using Power BI.
